## 固定する体験

- 写実的な生成写真、少ない言葉、静かな渡船場。8エリア・17課題と出航。
- 待合室は浮桟橋上にあり、低水位で構造が現れ、高水位で上の通路へ届く。
- 配管の連続、現物の反応、岸の位置と船底の深さを推理に使う。
- 知識の既読と物理状態は独立。初見で先に理解した操作を妨げない。
- 調べる→実物を操作する→開く→物を見る→自分で取るを区別する。
- 同一物の全景・接写・動作中・成功・取得後を一貫させる。
- 往復しても調整や未取得報酬が失われない。水位変更には常に帰路を持つ。

## 制作順序

1. 状態と断面、浮上区間の写真・操作を成立させる。
2. 観測・計測・航路の試作を成立させる。
3. 全部屋・短問・ヒント・保存を統合する。
4. 実画面で全課題の状態を確認、誤操作・保存再開を検証する。
5. 資産参照と採用原本を照合し、不採用の生成写真を削除する。

## 幾何の基準

水面は低0、中1.5、高3の三つの安定点。数値は世界の相対座標。
浮体の床面はmax(3.2, 水面+1)。低・中水位では固定受け台で床面3.2を下限として保持する。固定したまま高水位にしても床は水面3より上にあり、室内を不自然に浸水させない。
ジャッキは荷重を数cmだけ受け渡す機構で、ピンを外しても小屋が大きく落下することはない。
初期は整備固定具が床面3.2に保持。高水位で修復済み・固定解除済みなら床面4。
観測室の入口は床面4。岸側の廊下は4.2で、高水位3でも浸水しない。可動渡り板は長さ8、両端にヒンジと手すり。
固定柱と岸は移動せず、床・窓・小屋が同じ変位で移動する。
水位操作盤とすべての帰路は岸側。注水中に人が低い通路へ残る構成にしない。
船溜まりの船台は船底を2.48付近に保持。高水位3で喫水0.5の船底が2.5となり、船台をわずかに離れる。低・中では船台が支持する。岸上の予備型は全水位で観察・写し取りできる。

## 画像照合から具体化した点

- P01は三本の独立した留め金を自分で外す操作導入。順番を示す物理的な連結がない写真に、見えない順序条件を付けない。四つの短い局所パズルは工具箱・紙片・ベルト・分割環が担う。
- 注水は中央の給水弁が開けば成立し、他の弁の特定の組合せを不必要に要求しない。注水で水位を下げたり、排水で上げたりしない。
- 記録帳は観察時の水位や視点を保持した参照画面。記録帳から離れた現場の機械を操作しない。
- 予備船台は岸上に据える。水位を上げても消えず、写し取りにも低水位を要求しない。低水位を要するのは船体外側の補修・整備通路への立入りなど、実際に水が妨げる箇所。船の見えなくなった底を船台の写しから復元する推理は保持する。
- 船台の輪郭・浮上時の水線・測深棒は hull.ts の共通寸法を使う。写しを船へ重ねて、白い船底の印と青い水線の印を動かせる。50cmの喫水は物理量であり、正解の印を入力しないと船が動かないという知識フラグにはしない。
- P12の見通しは、同じ屋根記号を持つ二つの船着き場のうち現在地を定める。標を二つずつ選んで線を引くと、二組の交点が現在の渡船場に一致する。古い船着き場Xの深い出航側は二本杭A、現在地Sは輪Bなので、位置特定が航路選びに実際に関係する。
- 測量図の断面は一目盛10cmに統一し、中間目盛も10cm間隔で描く。小さすぎる断面で数え間違いを誘わない。

## 全景・接写・進行状態の整合性

- 船溜まりは一つの全景とする。左右の向き切替で同じ写真を拡大しない。船・船灯・水門・船台・水位目盛は全景上で直接選び、乗船と桟橋への帰路は明示したボタンから行う。旧セーブの船溜まりface=1はface=0へ正規化し、修理や道具などの進行は保持する。

- 固定施設と浮く待合室を区別する。待合室の渡り板は三室の施設棟につながる。町は海を隔てた遠景で、陸へ渡る橋は破損している。待合室の扉と窓は、内外の視点を反転しても配置が矛盾しない。
- 共通化するのは物理状態であり、すべての写真を拡大表示へ流用する規則にはしない。大きな景色の観察は構図を維持した限定的な拡大、小機構は専用の高解像度接写、資料は現場を背景にした読解表示、船内・船尾は別角度の専用写真とする。
- `DockView` は水位、浸水・修理、船灯、水門の状態を一か所で選ぶ。船の観察と木型接写の背景でも同じ状態を用いる。船台そのものは専用の高解像度素材を使う。
- 岸壁の目盛は岸に固定された水位の観察であり、喫水計測の入口ではない。修復船が浮いた後に船尾側へ回り、所有する写しを重ね、棒を添えて船底と水線を比較する。道具なしの白紙画面へは移動させない。
- 支持具の左右荷重・ピン、補修板・各ボルト・排水後の水位窓、船具ケースと引出しの取得物は全景と接写で対応させる。保存互換性で残る支持荷重1も表示する。
- 船灯の清掃と点灯は別の行為。装着前後どちらでもガラスを拭ける。つまみを回すだけで汚れを消さない。
- 水門を開いた後の観察では、実際に開いた門と海面を見せる。出航演出は修復船から海上へ遷移し、水位変更用の桟橋写真を挟まない。
- 手掛かりは観察時に自動記録し、手動記録ボタンを置かない。紙片は完成時にのみ図面を記録する。観測位置や測量図の線は観察中の操作に合わせて自動更新する。測線は `records.chart.chartMarks` に配列のコピーを保存し、現場を離れた後は観察時点の情報を保持する。旧セーブに項目がなくても読込み可能とする。
- 部屋の帰路と船溜まりへの入口は常時見える移動ボタンを持つ。目のボタン、訪問済みのマップは独立した操作。海上では現在地表示を「水路」にする。
