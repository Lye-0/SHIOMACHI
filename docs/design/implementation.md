## 固定する体験

- 写実的な生成写真、少ない言葉、静かな渡船場。8エリア・17課題と出航。
- 待合室は浮桟橋上にあり、低水位で構造が現れ、高水位で上の通路へ届く。
- 配管の連続、現物の反応、岸の位置と船底の深さを推理に使う。
- 知識の既読と物理状態は独立。初見で先に理解した操作を妨げない。
- 調べる→実物を操作する→開く→物を見る→自分で取るを区別する。
- 同一物の全景・接写・動作中・成功・取得後を一貫させる。
- 往復しても調整や未取得報酬が失われない。水位変更には常に帰路を持つ。

## 制作順序

1. 状態と断面、浮上区間の写真・操作を成立させる。
2. 観測・計測・航路の試作を成立させる。
3. 全部屋・短問・ヒント・保存を統合する。
4. 実画面で全課題の状態を確認、誤操作・保存再開を検証する。
5. 資産参照と採用原本を照合し、不採用の生成写真を削除する。

## 幾何の基準

水面は低0、中1.5、高3の三つの安定点。数値は世界の相対座標。
浮体の床面はmax(2.5, 水面+1)。低・中水位では固定受け台で床面2.5を下限として保持する。
ジャッキは荷重を数cmだけ受け渡す機構で、ピンを外しても小屋が大きく落下することはない。
初期は整備固定具が床面2.5に保持。高水位で修復済み・固定解除済みなら床面4。
観測室の入口は床面4。岸側の廊下は4.2で、高水位3でも浸水しない。可動渡り板は長さ8、両端にヒンジと手すり。
固定柱と岸は移動せず、床・窓・小屋が同じ変位で移動する。
水位操作盤とすべての帰路は岸側。注水中に人が低い通路へ残る構成にしない。
