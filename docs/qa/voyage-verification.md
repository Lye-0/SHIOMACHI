# 航路計画の確認（2026-09-20）

## 最終仕様

船に乗っても停泊状態。二本杭・輪の標と奥の三角標・石の門を見て、観測室で得た見通し線と照合する。測量図の二つの船着き場は名称で現在地を明かさない。

測量図に船着き場から沖の灯まで航路を引いて出港する。戻す・消す・景色へ戻る操作ができ、計画線は帰還・保存後も保持する。水深断面を選ぶと1cm目盛り、5cm長線の拡大図を表示する。正誤の着色は行わない。

出港は一括判定で、最初の障害に対応する画像のみを出す。浅瀬と梁は別の観察結果。途中で別分岐を選ぶことはできない。帰還後に計画を修正する。成功経路は S→B→C→E→G→H→T の6区間。Gは白い岩柱、Hは低い岩のアーチ。灯台を出口の視覚的な目印にした。

船底の深さは50cmの物理定数を維持し、入力した測定値で船の喫水を変えない。水深は46〜60cm、50cm以下を通過不可とする。S以外の船着き場を基準に描いた場合は、実際の出港地点からその方向へ進んで港口の浅瀬に当たるモデルで、別地点へのワープを許さない。

梁は事前に低水位の床下から観察できる。同じ割れた岬と三本松の島の間にある低水位・航行時画像を用意した。

## 検証

- `pnpm test`: 55件成功。S始点16経路、X始点16経路、計32本の単純経路を列挙し、安全な航路が上記1本だけになることを検証。
- 浅瀬が1区間目、2区間目、4区間目、5区間目にある経路、3区間目の梁、誤った出発位置を検証。最初の失敗地点・原因・画像を確認。
- 出港中の再出港・旧sail操作・航路編集で先へ進めないこと、未完・不連続・循環した航路を受け付けないことを確認。
- 計画・失敗の保存往復、旧セーブの10cm単位から1cm単位への移行、旧航行途中から船着き場への復帰を検証。終了済みセーブは終了を維持する。
- Playwright Chromeで失敗→帰還→消去→6区間の計画→到達を実操作。別途6種類の失敗を実操作し、該当場面だけになることを確認。
- 1440×1000と844×600で紙面と操作を目視。横方向の超過なし。水深図と標の操作領域の重なりを確認。
- 船尾の写しと棒を表示し、キーボードで水線の印を50cmへ合わせる操作を確認。二重に描かれていた目盛りを除去。
- 観測室の測量図にも断面拡大を追加し、目視確認。ブラウザのコンソールエラー0。
- TypeScriptと製品ビルド成功。画像112枚、欠落・未登録・不正寸法・未使用0。

## 航路編集UIの整理
景色では『航路図を開く』『岸へ戻る』のみ。航路図の下部は『図を閉じる』だけとし、沖の灯までつながった時だけ出港操作を追加。閉じた図の航路は保持する。戻す・引き直すは紙面の端へ移動。選択済みの標を押すとそこまで線を戻す。接続先の薄い輪、終点の輪、仮線、標名を追加し、安全性による正誤表示は行わない。航路計画中の小さな断面図を除き、水路の線から断面を確認する。狭幅では専用の水深拡大を開く。
Playwrightで未選択・途中・完成・図を閉じる・途中まで戻すの5状態のボタン構成と、ホバー仮線・キーボード選択・水深の開閉を検証。1440×1000と844×600を目視。狭幅の紙面は scrollHeight=clientHeight=418で縦の超過もない。58件のテストと製品ビルドが成功。

## 喫水の計測導線と記録
船尾の『棒を添えて測る』から、棒の持ち物選択を先に行わず計測できる。鉤として組み立て済みなら、その場で棒を外す操作を表示する。写しがあれば同時に重ねる。計測操作で水線記録に draftMarks を自動保存し、記録帳に印と間隔を表示する。再観察で計測値を消さず、誤った測定値も自動修正しない。旧セーブでは省略可能な記録フィールドとして扱う。
59件のテストとビルド成功。ブラウザで道具未選択から計測を開始し、水線の印を50cmへ動かして記録帳で印と『50 cm』を確認。47cmの誤測定、再観察、保存復元、50cmへの修正は回帰テストで検証。
