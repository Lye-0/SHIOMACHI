## 証拠の読み方

[点検表と修正内容](consistency-audit.md)、[状態名と操作結果](consistency-results.json)を参照。

`consistency/pair-states-00-0.jpg`〜`pair-states-33-0.jpg` は134状態の一覧。`consistency-results.json` の fixture と quadrant（左上0、右上1、左下2、右下3）を対応させる。

`consistency/flow-*.jpg` は通常プレイの途中状態、喫水のドラッグ計測、記録帳、船灯、出航、浅瀬・梁の反応、終章、狭幅UIの確認。出航演出に含まれる画像は dock-high、dock-high-open、boat-kit、boat-lamp、sea-night と航路標で、桟橋写真を含まない。

従来の50枚の一覧だけでは、全景と接写の連続性を十分に確認できていなかった。旧QA写真は今回の比較画像に置き換えた。最終状態の一括撮影はMCPの300秒応答上限を超えたが、134枚の保存と最終fixture番号133への到達を確認し、選択操作は4つに分けて再実行した。
