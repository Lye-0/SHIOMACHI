# 床下構造と補修の修正・確認（2026-09-20）

待合室は密閉した鋼製の箱に載り、固定案内柱に沿って上下する。固定ピンは柱と箱の受け金具をつなぎ、横の支持ジャッキが荷重を受ける。ピンがねじ軸を貫く旧構造は廃止した。

## 操作と表示

- 連絡桟橋の待合室直下の階段から床下へ入る。待合室からも降りられ、床下からは待合室へ戻る。マップの床下は待合室に接続する。
- 低水位だけ床下を歩ける。中・高水位で床下の足場は沈むが、主たる渡り板は歩ける。水位別の外観を更新した。
- 左右それぞれ、支持ねじを上げてからピンを抜き、支持ねじを下げる。抜去済みのピンは再び操作対象にならず、直接アクションを送っても荷重のエラーを返さない。
- ピンは所持品に入り、本数を表示する。従来のセーブは抜去フラグから所持を復元する。
- 補修セットは板・パッキン・脱落防止付きボルト4本の一式。損傷部に直接当てて向きを変える。穴が合った姿は実際の取付画像と共通で、取付時に位置が飛ばない。
- ボルトは締結後に再操作しない。4本すべて締めてから排水コックを開く。同じ壁面の水位管が空になる。
- クランクは差し込み先端を回転中心に固定する。回転中は固定具の二重操作を受け付けず、画面を離れるとタイマーを破棄する。
- 全景と接写はそれぞれのカメラ用画像を使い、同じ状態判定で表示する。全景の単純な拡大ではない。部材・壁面・光源の整合を目視した。

## 今回の検証

- Vitest 44件成功。ピンの荷重制約、抜去後の再操作、旧セーブ移行、補修セットの向き・締結・排水の回帰テストを追加。
- TypeScript・製品ビルド成功。アセット110枚、欠落・未登録・不正寸法・未使用0。
- Playwright Chromeで固定具と補修を実操作。ピン所持数2・抜去ボタン0、締結後ボルトボタン0・排水後コックボタン0を確認。
- 左右各4状態の直積16通りを全景と接写で撮影・目視。`pontoon-wide-grid.jpg` と `pontoon-detail-grid.jpg` は行が左、列が右。順に「ピンあり／ねじ下」「ピンあり／ねじ上」「ピンなし／ねじ上」「ピンなし／ねじ下」。
- 4本のボルトの16通りを撮影・目視。`patch-bolts-grid.jpg` は左上から行優先でビットマスク0〜15。
- 未補修、板を横に当てた状態、穴合わせ、締結、排水後、全景へ戻った状態を比較。
- 低・中・高水位の固定中・高水位の浮上後、床下の帰路、箱の開閉を確認。中水位初稿で渡り板への水面の重なりを検出し再生成した。
- 1440×1000と844×600で操作を確認。後者に横方向の超過なし。ブラウザエラー0。
- 既存の製品版セーブから「つづきから」で表示できることを確認。セーブの削除・初期化は行っていない。操作検証は保存領域を使わないVisualLabで実施。
